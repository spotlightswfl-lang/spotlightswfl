# Spotlight SWFL

A modern local business platform for Southwest Florida, designed to connect businesses, customers, deals, events, and community engagement in one place.

## Includes
- Business directory and local listings
- Photo/video showcase modules
- User and administrator login flows
- Community messaging and discussion boards
- Marketplace-style classifieds
- Coupon and QR-based offers
- Event and ticket sales
- Analytics dashboard
- Social media and Google Business integration hooks
- Streaming radio station pages

## Stack
- Next.js 14
- React 18
- TypeScript
- Tailwind CSS

## Getting started

```bash
npm install
npm run dev
```

Then open http://localhost:3000

## Structure

- `app/` — application pages and layouts
- `components/` — reusable UI elements
- `lib/` — site data and content definitions

## Notes
This is a kickstart scaffold for the product concept. It is designed to be extended into a production platform with authentication, database models, payments, real media uploads, and admin tooling.
